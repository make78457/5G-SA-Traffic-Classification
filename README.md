# 5G-SA-Traffic-Classification

This repository contains the research code for encrypted traffic classification based on 5G Standalone (5G SA) physical-layer channel records. The pipeline converts short PHY-layer log sequences into structured channel feature matrices and uses a hybrid neural network, BiLCNet, to learn traffic-related representations under different channel conditions.

The code is organized around two main stages: data preprocessing and model training/evaluation. It also supports multi-scenario learning and leave-one-domain-out (LODO) evaluation for assessing generalization to unseen gain settings.

## Overview

- **PHY-layer encrypted traffic classification**: classify traffic behavior without inspecting packet payloads.
- **End-to-end processing workflow**: raw 5G SA PHY logs -> cleaned records -> feature matrices -> model training and evaluation.
- **Hybrid architecture**: BiLCNet combines bidirectional LSTM encoding, Conformer blocks, attention pooling, and a multilayer classifier.
- **Generalization evaluation**: LODO experiments are used to test performance on unseen gain domains.

## Main Entry Points

- `Data_preprocess.ipynb`

  Preprocesses raw 5G SA PHY log files into model-ready samples. The notebook includes log parsing, header removal, record cleaning, sample construction, label assignment, and export of processed data files.

- `BiLCNet.ipynb`

  Defines, trains, and evaluates BiLCNet. This notebook loads the processed dataset generated by `Data_preprocess.ipynb` and includes both standard evaluation and LODO-style experiments across gain settings.

## Model Configuration

The main model used in the experiments is instantiated as follows:

```python
net = BiLCNet(
    input_dim=203,
    hidden_dim=64,
    lstm_layers=2,
    num_classes=4,
    num_conformer_layers=2,
    nhead=8,
    dropout=0.1,
)
```

### BiLCNet Hyperparameters

| Hyperparameter | Value | Description |
| --- | ---: | --- |
| `input_dim` | 203 | Feature dimension of each time step in the channel feature matrix. |
| `hidden_dim` | 64 | Hidden size of the bidirectional LSTM encoder. |
| `lstm_layers` | 2 | Number of stacked BiLSTM layers. |
| `num_classes` | 4 | Number of traffic classes in the classification task. |
| `num_conformer_layers` | 2 | Number of Conformer blocks after the BiLSTM encoder. |
| `nhead` | 8 | Number of attention heads in each Conformer block. |
| `dropout` | 0.1 | Dropout probability used in the LSTM, Conformer blocks, and classifier. |

Additional training settings used in `BiLCNet.ipynb` include:

| Setting | Value |
| --- | ---: |
| Batch size | 32 |
| Optimizer | AdamW |
| Learning rate | 0.001 |
| Weight decay | 0.01 |

## Reproducibility Notes

1. Run `Data_preprocess.ipynb` first to convert raw PHY logs into processed samples.
2. Run `BiLCNet.ipynb` to train and evaluate the model.
3. Keep the preprocessing configuration, data split strategy, and model hyperparameters fixed when reproducing the reported experiments.
4. For LODO evaluation, each target gain setting should be excluded from training and used only for testing.
